# Ankit Meena — Portfolio

Personal portfolio built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui
- Resend (contact form)

## ✨ Features
- Responsive design
- Dark/Light mode toggle
- Smooth scroll animations
- Resume download
- Working contact form
- Project showcase with tech tags

## 🛠️ Local Setup
\`\`\`bash
git clone https://github.com/ankitmeenamp/portfolio
cd portfolio
npm install
npm run dev
\`\`\`
